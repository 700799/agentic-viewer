# Canonical Trace Envelope

The single contract every adapter emits. Defined in
[`backend/app/schemas/canonical.py`](../backend/app/schemas/canonical.py); its JSON Schema
is served at `GET /api/v1/schema/canonical` and committed at
[`frontend/src/types/canonical.schema.json`](../frontend/src/types/canonical.schema.json).

> This is deliverable **#8 helper** — a full worked example lives at
> [`examples/example-trace.json`](examples/example-trace.json) (generated by the real
> Claude Code adapter).

## Enums

**Source**: `claude_code`, `openai_agents`, `langgraph`, `crewai`, `autogen`, `custom`.

**SpanKind**: `session_root`, `agent`, `llm`, `tool`, `mcp_tool`, `file_io`, `memory`,
`handoff`, `chain`, `retrieval`, `custom`.

**IOType**: `prompt`, `response`, `tool_input`, `tool_output`, `file_read`, `file_write`,
`memory_read`, `memory_write`.

**EdgeKind**: `call`, `handoff`, `data_flow`, `mcp_link`, `file_dep`, `memory_dep`.

## Rules

1. **Spans carry the tree.** `parent_external_span_id` defines the implicit `call` DAG.
   The `edges` array adds *extra* relationships (handoffs, data flow, file deps).
2. **External ids are adapter-local.** The projector resolves `external_span_id`,
   `agent_external_id`, and `mcp_server_external_id` to internal UUIDs.
3. **Cost is optional and trusted-if-present.** If `cost.cost_usd` is set it's used
   verbatim; otherwise it's computed from the `model_price` table (flagged `estimated`
   if the model is unknown).
4. **IO content is truncated** at ingest to `max_inline_content_chars` (default 20k);
   full bodies belong in an object store via `content_ref` (V1).
5. **Idempotency.** Re-ingesting the same `(source, session.external_id)` replaces that
   session's projection — safe for streaming/append and re-projection.
